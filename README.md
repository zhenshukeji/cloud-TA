> **智慧教育，触手可及 —— 云朵助教，让学习更懂你。**
>
> **云朵助教**是一套覆盖教务管理、招生营销、家校服务与多校区运营的教育管理产品，提供商业版与开源社区版。

## 1. 产品简介

**云朵助教商业版**面向培训机构、连锁校区及教育服务平台，覆盖以下产品模块：

- **机构端（PC 管理后台 + 微信小程序）**：教务、财务、招生营销、家校沟通；通过移动工作台处理课表点名、学员与班级管理及家校消息。
- **家长端微信小程序**：课表与课次查询、请假、作业、成长日志、在线购课与续费、家校沟通。
- **平台端**：机构入驻审核、平台财务、客服管理与平台人员权限，支持多机构平台运营。

**SaaS 版本已有 300+ 教培机构付费注册并投入生产使用，在真实教务与机构运营场景中持续验证和迭代。**
上述付费机构与生产使用情况指 SaaS 版本，社区版为其中单机构单校区教务能力的开源发行。

**技术栈**：Spring Boot + MyBatis + Vue.js + Element UI。社区版提供独立部署的管理后台和后端，
口令由环境变量注入，必需敏感配置缺失时拒绝启动。需要微信生态、招生营销、财务对账或多校区协作的，可直接了解商业版。

社区版实际交付范围以[第 2 节](#2-主要功能全景)的 ✅ 标记和[第 10 节对比表](#10-社区版与商业版对比)为准。

| 适合 | 不适合 |

## 5. 快速启动

### 方式 A：Docker Compose（推荐）

```bash
git clone <这个仓库地址> && cd community-edition
cp deploy/.env.example deploy/.env
#   编辑 deploy/.env：至少改 MYSQL_ROOT_PASSWORD / MYSQL_PASSWORD / REDIS_PASSWORD /
#   TOKEN_SECRET / INITIAL_ADMIN_PASSWORD（每个都有生成命令写在旁边）

docker compose --env-file deploy/.env -f deploy/docker-compose.yml up -d --build
docker compose --env-file deploy/.env -f deploy/docker-compose.yml ps    # 四个服务都应是 healthy
```

打开 `http://<你的机器>:8080`，用 `admin` + 你设的 `INITIAL_ADMIN_PASSWORD` 登录，**首次登录会要求改密**。

想一并导入演示数据（虚构机构「春芽艺术工作室」）就在命令里再加一个 `-f deploy/docker-compose.demo.yml`。
配置、部署步骤与注意事项见 [Docker 部署指南](deploy/README.md)。

### 方式 B：本地直接跑

1. **准备数据**：建库（要求库名前缀 `yunduo_community`），依次执行
   `database/001_schema.sql` → `database/002_seed_system.sql`（→ 可选 `database/003_demo_data.sql`）
2. **准备 Redis**：建议用独立逻辑库（默认 12）
3. **配置环境变量**：复制 `scripts/env.local.example` 为 `scripts/env.local`，填写配置后执行 `set -a && source scripts/env.local && set +a`
4. **起后端**：`cd backend && mvn -o spring-boot:run`（JDK 8 + Maven）
5. **起前端**：`cd admin-web && npm ci && npm run dev`（依赖已由 `package-lock.json` 锁定；`legacy-peer-deps` 已由 `.npmrc` 固化；Node 22/24 需 `NODE_OPTIONS=--openssl-legacy-provider` 跑生产构建）

需要的最小环境变量只有 9 个：`MYSQL_HOST/PORT/DATABASE/USER/PASSWORD`、`REDIS_HOST/PORT/PASSWORD`、`TOKEN_SECRET`；
空库首次启动还要 `INITIAL_ADMIN_PASSWORD`。**少任何一个，后端都会明确拒绝启动**（不会偷偷用默认值）。

## 6. 演示数据
部署完的系统是空的。如果想先看到一间「正在上课」的机构，再开始录入自己的数据，
可以在初始化时多执行一个脚本 —— `database/003_demo_data.sql`。

它会为你准备一间虚构的「春芽艺术工作室 · 阳光校区」：三位老师带着三个班，
10 个孩子分别处在续费后课时充足、快要上完、经常请假等不同状态；一周的课表已经排好，
最近五次课的点名记录、报读登记和对应的课时流水也都齐了。也就是说，打开课表能点名，
打开统计能看到真实的出勤分布，打开学员账户能看到每一笔课时是怎么增减的——
正好把系统从头到尾走一遍，再决定怎么把自己的机构录进去。

这间机构完全是虚构的：姓名是编的，电话统一用 `199` 开头的占位号段，没有身份证号、
没有微信 OpenID，SQL 文件里也不含任何口令——口令由你自己在下面这一步设置，
脚本会把它们写进数据库，而不是留在任何文件里：

```bash
set -a && source scripts/env.local && set +a
export DEMO_PASSWORD='<你自己定的演示口令>'
python scripts/set-demo-passwords.py
```

生产环境不用导入这个文件——只执行 001 和 002 两个脚本，得到的就是一间空机构。

## 7. 备份、恢复与升级
- **备份**：MySQL 逻辑备份（`mysqldump`）即可覆盖全部业务数据；上传目录（`UPLOAD_ROOT`）单独归档；
  Redis 只存登录态与限额，**不需备份**（丢了只会让所有人重新登录）。
- **恢复**：先恢复库，再恢复上传目录；顺序不能反（否则期间的新上传会被覆盖）。
- **升级**：先备份 → 拉新代码 → `001/002` 是幂等脚本可安全重复执行 → 启动后端（首次启动会自动做必要初始化）→
  清浏览器缓存重登。
- **注意两种「升级后会重新登录」的情况**：① 换了 `TOKEN_SECRET`；② 从更早版本升级到本版
  （登录令牌的 Redis key 加了应用级前缀，旧令牌会失效）。
- 备份、恢复与升级见 [运维手册](docs/OPERATIONS.md)；首次配置要求见[部署文档](docs/DEPLOYMENT.md#2-部署前必读)。
- 部署指南（源码/Docker 两种方式、升级、常见问题）见 **`docs/DEPLOYMENT.md`**。

## 8. 安全与漏洞报告
- 口令：只接受环境变量注入；初始管理员口令有强度硬校验，不达标**拒绝启动**；演示数据不携带任何口令。
- 令牌：JWT + Redis 登录态，密钥强度硬校验（长度 ≥ 32、不同字符 ≥ 8、拒绝占位符）；登录失败次数超限临时锁定。
- 权限：接口级 `@PreAuthorize` 鉴权；权限拒绝的形态是 **HTTP 200 + `body.code=403`**（客户端判码，不判状态码）。
- 暴露面：默认关闭 Swagger 与 Druid 控制台；Docker 部署只发布前端端口，MySQL/Redis 不对外。
- **发现安全问题请勿直接开公开 Issue**，请发邮件至 duanmingwei@szzhenshu.com，标题以 `[SECURITY]` 开头；请勿附带真实师生资料或生产凭据。
- 项目沿用 Java 8、Spring Boot 2 与 Vue 2 技术栈，存在历史依赖安全债务；上线前请检查依赖更新并按部署环境做好访问控制。

## 9. 测试与验收
- 后端集成测试：`cd backend && mvn -o test -Pcommunity-verify`（12 项最低测试集 = 15 个用例，含负向对照）。
  注意：pom 里有 `skipTests=true` 用于打包提速，**必须带 `-Pcommunity-verify`** 才会真的跑；
  `Tests run: 0` 就是漏带了 profile。
- 首次在全新机器上跑测试需要联网（Maven 要下载 surefire provider），之后就支持离线。
- 部署后的业务检查：登录 → 新建教师、课程、班级及学员 → 登记报读 → 排课 → 点名 → 核对剩余课时与流水。请在独立测试环境使用虚构数据。

### 10.1 管理后台精简明细（社区版相对商业版删了什么）

社区版管理后台不是简单去掉小程序端，而是按「单机构教务最小闭环」做了四层精简：

**整包移除的模块**（社区版后端业务包只剩 `base` / `educenter` / `statistics` / `project` 四块）

| 商业版模块 | 内容 | 社区版 |
|---|---|---|
| 销售中心（sale） | 线索收集、公海池、线索分配、跟进转化 | ❌ |
| 家校沟通（homeschool） | 家校通聊天、通讯录、消息 | ❌ |
| 在线课程（online） | 直播、录播课程 | ❌ |
| 微官网（website） | 校区主页、资讯、信息收集 | ❌ |
| 平台端（platform 等） | 多机构入驻审批、平台财务、客服管理、平台人员角色 | ❌ |

**共用模块里删除的接口**（8 处，社区版代码中不存在）

| 位置 | 删除的接口 | 影响 |
|---|---|---|
| 账号（BdAccess） | 机构注册 `/reg`、平台资讯 `/info` `/getUser`、消息 `/notify`、找回密码 `/forGetPassword` | 平台化注册/资讯/找回密码入口不存在 |
| 校区（BdCampus） | 删除校区、校区详情、经纬度校验 | 配合「单机构单校区」收敛，**社区版不能删校区** |
| 机构（BdMechanism） | 机构切换 `/change`、手机校验 | 无多机构切换 |
| 课程 / 班级 | 体验课列表 `/experienceList` | 无体验课查询 |
| 报读情况 | 导出 `/export` | 社区版报读页没有导出功能 |

**整文件缺失的统计与教务能力**

- 教师评价（BdTeacherEvaluation）、续费预警名单（RenewalError）
- 续费统计、学费统计（RenewalStatistics / TuitionStatistics）——社区版统计只剩班级明细、学生考勤、学生课次 3 张报表

**基础能力替换**

- 微信支付：无（社区版收款只走线下登记 `amount_cny`）
- 短信验证码、模板消息：无
- 对象存储：改为本地文件存储（`CommonController`）
- 分销、拼团、直播相关代码为 0

**菜单收敛**：社区版共 18 个页面——首页、教务中心（课程/学员/班级/报读/课表/上课记录/教师 7 页）、统计数据（3 页）、基础信息（用户/角色/菜单/字典/校区人员/日志 7 页）；商业版另有销售中心、财务、家校沟通、在线课程、微官网、平台管理等目录。

## 11. 商业版

商业版提供教务、财务、招生营销、家校服务、移动端与多机构平台运营模块，既适用于需要家长端和招生工具的单校区机构，
也适用于多校区机构和教育服务平台。可按实际使用场景咨询功能范围、产品演示与交付方案。

双许可与适用范围见 [商业许可说明](COMMERCIAL-LICENSING.md)。

### 11.1 商业版模块清单

以下按平台端、机构端、增值功能及小程序端列出商业版模块；与社区版的能力差异见[第 10 节](#10-社区版与商业版对比)。

**平台端（总部运营）**
- 机构入驻与审核、机构信息与品牌定制、微官网/资讯/市场活动审核
- 平台财务：机构流水、家长流水、财务对账
- 客服管理、平台人员与角色、Banner 与资讯配置

**机构端**
- 多校区总部管理与校区维护升级
- **销售中心**：线索收集、公海池、线索分配、跟进记录与转化分析；微官网留资表单收集的线索可**用云朵点解锁联系方式**，广告投放来的流量直接沉淀为可跟进线索
- **营销增长**：分销活动、拼团活动、市场活动与效果分析
- **在线课程**：直播课程（播放/回放/互动/分享/分析）、录播课程（购买/分销/分析）
- **运营触达**：续费预警批量发送、考勤通知、上课提醒（短信/微信模板消息）
- **微官网**：校区主页定制、信息收集与展示、校区资讯

**增值功能运营体系**（管理后台内置）
- **云朵点账户**：机构在线充值、账户流水、支付回调核销，直播/录播等增值功能按云朵点/时长开通与到期管理
- **会员体系**：机构加入会员、到期时间管理，增值功能随会员档位解锁
- 意思是：新能力的开通、计费、续费都在后台自助完成，不需要人工对接

**家长端微信小程序**
- 微信登录认证、OpenID 绑定、验证码
- 附近机构 / 附近课程 / 附近活动发现；机构内容推荐
- 在线购课与**微信支付**、云朵点充值、我的课程与在线续费
- 拼团、分销中心（分销订单与提现）
- 课表、作业、成长日志、请假、课次查询、意见反馈、教师评价
- 家校通：与老师聊天、通讯录、消息通知、微信订阅消息提醒

**机构端小程序**
- 移动工作台、课表与点名、学员与班级管理、家校通消息

### 11.2 哪些场景适合选择商业版

| 使用场景 | 对应模块 | 可预约的演示流程 |
|---|---|---|
| 单校区需要家长自助查课、家校沟通与在线续费 | 家长端微信小程序、课表与课次查询、家校通、在线购课与续费 | 家长查询课表与剩余课次 → 在线续费 → 后台查询订单与记录 |
| 招生线索需要集中分配、跟进并转为学员 | 销售中心、公海池、线索分配与跟进、微官网留资、营销活动 | 留资 → 线索分配与跟进 → 转化记录与学员管理 |
| 多个校区需要按岗位协作、统一查看业务 | 多校区管理、人员角色权限、统计报表与财务核对 | 总部与校区角色切换演示 → 查看授权业务与相关报表 |

不经营多机构 SaaS 平台，也可以因家长端、招生跟进或多校区管理需要选择商业版。
演示及交付范围按具体版本与所需第三方条件确认。
